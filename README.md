# DoNation GitHub Governance

This repository contains DoNation's organization-level development contribution standards and default pull request guidance.

## Source of Truth

- **GitHub** is the source of truth for delivered code and pull request history.
- **Jira** is the source of truth for work authorization, acceptance criteria, testing evidence, defects, and closure.
- **DEV-1278** governs Jira-to-GitHub traceability.
- **DEV-1363** governs creation and publication of this organization-level `.github` repository.

## Files

- `CONTRIBUTING.md` — required development and pull request practices.
- `SECURITY.md` — secure reporting and handling expectations.
- `.github/pull_request_template.md` — default PR information and checklist.

These standards apply to DoNation repositories unless a repository-specific standard is stricter.
